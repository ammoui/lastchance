# Последний шанс

VR-игра на Unity: игрок рисует руны в воздухе, а жест превращается в заклинание.
Сейчас в проекте есть комната с колоннами, телепорт и след палочки.

Версия Unity: 6000.3.27f1 (6.3 LTS).

## Запуск

Открыть проект в Unity Hub, открыть сцену `Assets/Scenes/Room.unity` и нажать Play.
Если шлем подключён, игра идёт на нём. Без шлема сам запускается XR Device Simulator.

## Управление на шлеме

- Левый стик вперёд: дуга телепорта, отпустил — перемещение.
- Правый курок: зажать и рисовать руну.

## Управление в симуляторе

- Кликнуть в окно Game.
- `T`: левый контроллер, `W`: стик вперёд.
- `Y`: правый контроллер, левая кнопка мыши: курок.
